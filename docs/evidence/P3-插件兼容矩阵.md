> 样本：**28 个真实 npm 产物**（从 npm 搜索 + unpkg/jsdelivr 递归抓取 client 模块图，非手写 demo）

## 门禁判定

| 项 | 要求 | 实测 | 结论 |
|---|---|---|---|
| A 级（可用）数量 | ≥ 15 | **20** | ✅ 通过 |
| 导致 App 崩溃的插件 | 0 | **0** | ✅ 通过 |
| C 级（渲染失败） | — | **0** | 全部修完 |

A/B/N 口径：**A** = 每个注册的 slot 都渲染出节点且无错误；**B** = 能渲染但有明确受限原因（P3.5 依赖 / 需宿主数据 / 部分 slot 返回 null）；**N** = 客户端只注册了能力、没有 UI slot，**不计入分母**。

## C → A 的五个修复（P3 收尾）

这五个插件最初都是 C 级（渲染失败）。每一个都暴露了宿主的一个真实缺陷，而不是插件的错：

| 插件 | 原始症状 | 根因 | 修复位置 |
|---|---|---|---|
| `console` | `Element type is invalid … got: undefined`（`IconSearchOutline16`） | `flexModule` 的兜底挂在 Proxy `get` 上，而插件用 esbuild `__toESM` 做 CJS 互操作 —— 它只复制**自有可枚举**属性，生成的图标全被丢成 `undefined`。改为把兜底挂到**原型链**（`__toESM` 会继承原型） | `src/host/index.mjs` |
| `console` | `Cannot read properties of undefined (reading 'bootstrap')` | 槽位注册的 `register({ inject: () => ({ api }) }, C)` 中 `inject` 是个**返回额外 props 的函数**，宿主从未调用 | `src/pipeline.mjs` |
| `console`/`relay` | `getLocale is not a function` / 文案显示 `relay-ui:title` | `locale` 服务缺 `getLocale()`；`register(ns, dict)` 存的是裸键，而查询用的是 `ns:key` | `src/host/locale.mjs`、`src/services.mjs` |
| `relay` | `Cannot read properties of undefined (reading 'getSnapshot')` | 同上 —— `getSnapshot()` 缺 `active` 字段，插件写 `getSnapshot().active.startsWith('zh')` | `src/host/locale.mjs` |
| `share` | `Objects are not valid as a React child (found: object with keys {type, id, text})` | 宿主 `Menu` 原语把 `{type:'label', text}` 分组项整个对象当 child 渲染 | `src/host/primitives.mjs` |
| `core-demo` | 加载期 `patterns[i2].replace is not a function` | 跨 realm `instanceof`：沙箱注入宿主 `RegExp`，而脚本里的正则字面量用 vm 自己的内置构造器，`/re/ instanceof RegExp` 恒为 false | `src/loader.mjs`（品牌检查 shim） |
| `core-demo` | `rootRef.current?.querySelector is not a function` | `ref.current` 只是裸 IR 节点，没有 DOM 方法 | 新增 `src/refdom.mjs` |

## 矩阵怎么读

1. **节点数**是渲染深度的粗略代理：`uisfx` 938 节点说明它把整页 UI 都交给了宿主，不是「渲染了个空壳」。
2. **能力列**列的是插件自己声明的重能力（canvas/video/iframe/webgl）。声明了重能力的插件即使渲染成功也只能是 B —— 写 A 就是撒谎。canvas 是这条规则的例外说明：桥（指令录制 + 原生重放）与动画采样已经实现并有 32 条测试，但交互（拖拽旋转、hover）仍不响应，所以仍然是 B。iframe 同理：srcdoc 物化已实现（§11），但分级用的是**这一次渲染的实际结果**（`countFrames`）—— 渲染出来的 iframe 全部有 frame 才豁免，否则保持 B 并把原因写成 `iframe(src-only)`。
3. **N 级不计入分母**：`muyu`/`update` 的客户端只注册了拖拽/更新这类宿主能力，本来就没有 UI。把它们算进「不可用」会人为压低通过率。
