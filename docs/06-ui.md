# 06 · 界面：和桌面客户端对齐到什么程度

原则：**观感对齐，结构让步**。手机上放不下三栏，但配色、圆角、字号、行高、
间距这些"一眼能认出是同一个产品"的东西不能自己拍。

## token 从哪来

不估、不参考，直接从上游包里抠：

| 来源 | 内容 |
|---|---|
| `node_modules/@deepseek-ai/dsh-client-ui-theme/lib/client.js` | `design-platform.css` 里的 119 条 `--dsw-alias-*`，两套作用域（`body` = 浅色，`body[data-ds-dark-theme]` = 深色） |
| `node_modules/@deepseek-ai/dsh-web-frontend/dist/assets/index-*.css` | `--dsw-specific-*`：气泡、侧栏、输入框的底色，这些不在 alias 表里 |
| `dsh-client-ui-layout/README.md` | 三栏几何：侧栏 264–420（默认 280）、折叠 56、右面板首次 45% |

落点是 `impl/app/lib/dsh_tokens.dart`（`DshPalette` 原表 + `DshTokens` 语义层）。
`theme.dart` 只负责把 IR / 插件用到的旧键名映射过去，不再自带一套近似色。

## 几个必须知道的真值

| 项 | 浅色 | 深色 |
|---|---|---|
| 应用底 `bg-base` | `#fff` | `#151517` |
| 侧栏 `sidebar-fill` | `#f9fafb` | `#1b1b1c` |
| 侧栏选中 `nav-item-active` | `#ebeef2` | `#43454a` |
| 用户气泡 `specific-bubble` | `#edf3fe` | `#2c2c2e` |
| 主色 `brand-primary` | `#0f1115` | `#f9fafb` |
| 描边 `border-l2` | `#0000001a` | `#ffffff1f` |
| 错误 `state-error` | `#ec1313` | `#f25a5a` |

**主色是黑白，不是品牌蓝。** 蓝色（`link` = `#4176e6`）只出现在链接和选中态。
用 M3 的 `ColorScheme.fromSeed` 会生成一整族紫灰，那是另一套语言 —— 所以
`main.dart` 的 `_theme()` 里把 `primary/onPrimary/surface/outline…` 逐项覆盖成 token。

## 布局

| 位置 | 桌面原版 | 这里 |
|---|---|---|
| 侧栏 | 280，可折到 56 rail；<768 变抽屉 | 同（≥900px 三栏，窄屏是"列表 ↔ 对话"两页） |
| 对话列 | `max-width: 748`，居中 | 同（`_Centered`，窄屏退化成 16 留白） |
| 用户消息 | 右对齐气泡，`radius-xl`(20)、`padding 10/16`、14/22 | 同 |
| 助手回复 | **无气泡**，正文直接落在背景上，14/24 | 同 |
| 消息间距 | 同轮 4，跨轮 12–16 | 16 |
| 输入框 | 大圆角框 + 右下发送钮 | 圆角 24 + 右侧 34 圆钮（手机把发送钮放框外，框内右侧会挤掉输入宽度） |
| 右面板 | 首次 45% 视口，上限 70% | 固定 340（再宽就吃掉对话列；窄屏走底部抽屉） |

## 刻意偏离

1. **AppBar 保留**。原版顶栏是窗口 chrome，手机上需要一个能放返回、标题、
   工作台入口的地方。视觉上压到 15/500、不投影、与内容同底。
2. **设置是整页 push**，不是"主区切成设置面板"。手机上 push 才有返回手势。
3. **会话行单行**（标题 + 时间），不带预览。原版侧栏就是这样；preview 仍参与搜索。
4. **字体用系统 sans**。原版 brand 是 Montserrat，正文是 `--dsh-font-family-text`；
   Android 上落到 Roboto/思源，字宽有差异，属于"允许偏差"。

## 怎么看效果

`test/shots.dart` 不是测试套件的一部分（文件名不是 `*_test.dart`），需要时显式跑：

```
flutter test --update-goldens test/shots.dart
```

会在 `/tmp` 写出宽屏三栏、窄屏列表/对话、深色、rail、启动态六张图。改完样式先看
图再跑全量测试 —— 断言能保证结构，保证不了"看起来像不像"。
